# 第 28 章：pi-web-ui — 浏览器里的复用

来源：[《pi 的设计艺术》第 27 章：pi-web-ui — 浏览器里的复用](https://zhanghandong.github.io/pi-book/ch27-web-ui.html)

## 设计问题与机制

历史 pi-web-ui 使用 Lit 组件直接消费 Agent 事件，把聊天、模型选择、会话及附件预览组合为浏览器入口。它与 CLI 是共享底层能力的并列消费者。会话持久化使用 IndexedDB，文档预览依赖浏览器解析组件。

前端独自承担附件、存储、凭证及网络条件。浏览器中预览文档不等于随后的模型请求不会上传内容；较少的框架依赖也不等于较小的文档处理依赖。

## 工程应用检查（独立推导）

博客可借鉴“事件契约共享、展示独立”，无需为复用而换成 Lit。附件预览与送入模型应是两个可观察动作；大文档库按需加载。浏览器直连前单独验证提供方跨域行为及凭证方案。草稿存储、公开发布和对话上下文也应有不同状态，避免一次预览意外变成公开或发送。
