怎么用这份橱窗

看某个产品时别只看首页，优先点进“登录后的界面”或文档页——营销页好看是常态，能反映功力的是密集信息的排布。

每张卡的要点是判断依据，不是事实断言；界面会改版，看到不一致时以你眼前的实际页面为准。

推荐路线

  1. 先挑 3 个产品界面，截图存成一册
  2. 挑 1 个组件库跑起来，只改 token 换配色
  3. 用 Codrops / CodePen 抄一个微交互
  4. 回到自己的页面，只改间距与层级
